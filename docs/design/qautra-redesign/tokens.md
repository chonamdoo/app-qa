# QAutra 재설계 · 공통 디자인 토큰

기준: [최종 제품 설계](../../plans/2026-11-01-qautra-product-design-brief.md), [사용자가 확인한 Space 참고 기준](rival.md), 원본 `qautra-design-package.zip`.

상태: 사용자 검토용 디자인 제안. 제품 CSS/SwiftUI를 수정한 값이 아니며 아직 렌더·접근성 실기 검증을 하지 않았다.

## 1. 색과 대비

원본의 밝은 shell·파란 primary·의미별 상태 색을 유지한다. 흰 surface는 고정된 원본 디자인의 선택이며 장식용 gradient/glass는 추가하지 않는다. 의미 있는 상태는 아이콘·문구와 함께 표시하고 성공 색을 비간섭 인증으로 쓰지 않는다.

아래 대비는 sRGB 상대 휘도 공식으로 계산한 색 조합 값이다. 실제 렌더의 글자 굵기·focus·투명도·상속·표면을 검증한 결과는 아니다. 본문은 4.5:1 이상, 조작 경계/초점은 인접 표면과 3:1 이상을 기준으로 한다.

| 역할 | foreground / 실제 배경 | 계산 대비 | 사용 조건 |
|---|---|---|---|
| 기본 본문 | `#20232c` / `#ffffff` | 15.69:1 | text-safe |
| 보조 본문 | `#687180` / `#ffffff` | 4.93:1 | text-safe. 중요한 오류를 작은 metadata로 숨기지 않음 |
| canvas 보조 본문 | `#687180` / `#f8f9fb` | 4.68:1 | text-safe |
| primary 버튼 | `#ffffff` / `#4266e8` | 4.89:1 | text-safe. 한 작업 영역의 주 행동에 제한 |
| 선택된 nav/링크 | **`#3152c6`** / `#edf1ff` | 5.91:1 | text-safe. 원본 `--blue-dark` 재사용 |
| 성공 상태 | `#24734f` / `#eaf6ef` | 5.20:1 | text-safe, 성공 아이콘/문구 병기 |
| 실패 상태 | `#c04449` / `#fceff0` | 4.50:1 | text-safe 계산 경계에 가까움. opacity 사용 금지, 렌더 재측정 |
| 주의/준비 필요 | `#93651c` / `#fcf5e7` | 4.70:1 | text-safe, 경고 원인·해결 행동 동반 |
| 입력/선택 경계 제안 | **`#7d8593`** / `#ffffff` | 3.72:1 | ui-safe, 본문용 아님 |
| 단순 구분선 기존 | `#e6e8ed` / `#ffffff` | 1.23:1 | decorative. 입력의 유일한 경계로 사용 금지 |

원본 `#4266e8` 글자를 `#edf1ff`에 놓으면 4.33:1이므로 일반 크기 선택 label에는 쓰지 않는다. 버튼 fill은 그대로 유지하고 선택 label만 기존 dark token으로 바꾼다. 새 `--control-border` 후보는 공통 원본에 추가하는 최소 변경이다.

## 2. 한국어 타이포그래피

한 시스템 계열 `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", sans-serif`로 본문·제목·제어를 통일한다. 원본 QAutra wordmark/아이콘은 그대로 사용하며 한글 제목에 별도 장식용 서체를 얹지 않는다. 숫자 열에는 tabular numerals, 원시 ID/코드에만 monospace를 사용한다.

| 역할 | 제안 크기/굵기/line-height | 출처/제약 |
|---|---|---|
| 화면 제목 | 28px / 650 / 1.35 | 최종 문서 §12와 원본 `--h1` |
| 영역 제목 | 20px / 650 / 1.5 | 원본 h2 역할 |
| 일반 본문/검토 내용 | 16px / 400 / 1.65 | 원본 `--body`; 줄 길이 최대 약 68ch, 한국어는 실제 줄바꿈으로 검수 |
| compact 제어/표 | 13px / 400 또는 550 / 1.6 | 원본 `--small`. 결과·오류 의미를 읽을 수 있어야 함 |
| raw ID 보조 | 11px / 400 / 1.8 | 원본 metadata. 전체 값 보기/복사 제공 |

웹 일반 floor의 display/body 2.5배 규칙보다 기존 생산성 앱의 28/16 크기를 우선한다. 마케팅 hero가 아니라 데이터/업무 앱이라는 최종 문서의 지정 때문이다. 200% 확대와 좁은 창에서 동작을 숨겨 해결하지 않는다.

날짜는 `2026년 11월 01일 10시 30분 05초 KST`처럼 표시하고 UTC/원시 ID는 상세·복사로 제공한다. 예시 시각은 디자인 샘플임을 표시하며 실제 실행 기록으로 제시하지 않는다.

## 3. 배치와 간격

밝은 왼쪽 navigation을 유지하고, 작업의 중심을 실행 상세에 둔다. 그 안의 관측·검증·증거 정보 우선순위만 세 가지 구조 시안에서 비교한다.

```text
┌──────────────┬─────────────────────────────────────────┐
│ QAutra       │ 프로젝트 · 현재 화면 · 디자인 예시 표시 │
│ 프로젝트     ├─────────────────────────────────────────┤
│ 실행 현황    │ 제목 / 상태 / 문맥별 주 행동             │
│ 시나리오     │                                         │
│ 요구사항 추적│ 시나리오·실행·Space·증거의 본문           │
│ 환경 및 기기 │                                         │
│ 리포트       │ 실행 결과 / 수집 상태 / 정리 상태 분리   │
│ 증거 보관함  │                                         │
│ 설정         │                                         │
└──────────────┴─────────────────────────────────────────┘
```

- 간격은 원본 4/8/12/16/20/24/32/40/48px scale을 사용한다. 내부 관련 항목 8–12px, 별도 그룹 24–32px.
- sidebar 기본 228px, 원본 1100px 이하 196px 동작을 출발점으로 삼는다. 제목/내용이 잘리면 실제 렌더 후 조정한다.
- 기본 content 여백 32px, 넓은 창 최대 40px. 원본의 1680px content cap을 재검토 기준으로 사용한다.
- panel radius 12px, control radius 8px. 모든 영역을 독립 카드로 감싸지 않고 표/목록/구분선으로 정보 관계를 표시한다.
- 일반 control 높이 40px를 유지한다. 좁은 터치 대응 영역은 최소 44px. icon-only 제어는 접근 가능한 이름·즉시 보이는 focus를 가진다.
- 1024×768 / 1440×900 / 1920×1080 CSS px에서 검수한다. 이것은 실제 Mac 최소 창/지원 하드웨어 보장이 아니다.
- 넓은 표만 자체 container에서 스크롤한다. 전체 창의 가로 overflow로 정보를 숨기지 않는다.

## 4. QAutra를 식별하는 공통 요소

**실행 상세의 ‘실제 대상 + 관측 시각 + 자동 실행의 입력 경계’ 표시**를 Space/Replay에 일관되게 둔다. 대상이 Chrome/Safari인지, 실제 연결인지 저장 화면인지, 입력이 어디로 전달되는지 혼동하지 않게 한다.

- 프로토타입 전체: `디자인 예시 · 실제 테스트/연결 없음`을 지속 표시.
- 실행 관측 예시: 실제 target의 샘플 정보, `자동 실행`, capture 범위·시각. `호스트 입력을 사용하지 않는 설계`는 요구 안내이지 검증 완료 badge가 아님.
- Replay: `저장 영상 · 읽기 전용`. 녹화 저장 중/불완전/만료를 실제 상태와 분리.
- 사용자 개입: `자동 실행 종료 후 진단`. 일반 자동 회귀로 돌아가는 `AI에 반환` 버튼 없음.
- 기본 순차·자원 대기는 설명 가능한 문구로 제공. Space 카드 개수나 프로필 등록 수를 동시 실행 수로 쓰지 않음.

근거는 최종 문서 §4·§8–10·§12와 `rival.md` 1–5다. 파란 광택 테두리나 실제와 무관한 안전 인증 장식이 식별 요소가 되지 않게 한다.

## 5. 공통 상호작용과 이후 검수

- focus: 3px `--blue-dark` outline, offset 3px, 즉시 표시. 포인터 hover에만 의미/행동을 숨기지 않음.
- 동작: 원본 180ms 이내의 색/표면 피드백을 후보로 유지. 화면 전환 모션은 아직 참고 영상 근거가 없으므로 별도 과장하지 않음. reduced-motion에서 제거.
- 모달: 제목·동작 영향·취소/진행을 명시, ESC/취소는 상태 변경 없이 복귀, 닫으면 호출 지점 focus 복원.
- loading/empty/error/disabled: 각각 내용 구조·현재 상태·원인·가능한 다음 행동을 설계. 스피너만 표시하지 않음.
- selection/caret/focus/scrollbar는 공통 token을 사용한다. 링크는 색 외 밑줄/명확한 문맥을 갖는다.
- 검토·실행·복구·증거의 상태 색이 원 결과를 바꾸지 않는다. unknown은 준비 완료나 PASS가 아니며 disabled 이유는 tooltip 밖에도 표시한다.

원본에서 재사용할 source는 `ui/tokens.css`, `ui/components.{css,js}`, `ui/examples.json`, `assets/icons/`다. 시안별 HTML/CSS를 복제해 별도 시스템을 만들지 않는다. 다음 단계의 구조 시안은 이 토큰을 공통으로 사용하고 **화면 구성 축 하나만** 달리한다.
